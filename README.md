# ✈️ AI Travel Planner (MVP)

一个基于 AI 的旅行行程生成工具（MVP版本），支持：
- 自动生成旅行行程
- 美观展示（表格+分天结构）
- 一键导出 PDF
- 简易付费解锁（微信扫码）

---

## 🚀 项目简介

本项目是一个轻量级 AI 旅行助手，用户只需输入旅行需求，即可自动生成完整行程，并支持导出 PDF 文件。

核心目标：
- 降低旅行规划成本
- 提供结构化、可分享的行程
- 构建未来可扩展的 AI Travel Infrastructure

---

## 🧩 核心功能

### 1️⃣ AI 自动生成行程
- 输入自由文本（时间 / 人数 / 预算 / 偏好）
- 调用 DeepSeek API
- 输出结构化 Markdown 行程
- 自动按 Day 分组展示

---

### 2️⃣ 行程可视化展示
- 自动转换 Markdown → HTML
- 表格形式展示每日安排
- 支持移动端适配
- 自动分页（PDF打印优化）

---

### 3️⃣ PDF 导出功能
- 一键导出 A4 PDF
- 自动生成文件名（基于行程标题）
- 支持高清导出（html2canvas）

---

### 4️⃣ 简易付费系统（MVP）
- 下载 PDF 前需付费（单次付费）
- 微信二维码支付
- 手动输入订单号验证
- 本地 localStorage 控制权限

---

## 💰 收费逻辑

| 行为 | 是否收费 |
|------|--------|
| 生成行程 | 免费 |
| 下载 PDF | 需要付费 |

规则：
- 每次新生成行程 → 需要重新付费
- 同一行程 → 可重复下载
